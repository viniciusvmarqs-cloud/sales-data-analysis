# Sales Data Analysis

Python project for analyzing sales data and generating business insights using Pandas and Matplotlib.

## Technologies

* Python
* Pandas
* Matplotlib

## Features

* Reads Excel sales data
* Calculates total revenue
* Calculates average revenue
* Finds highest sale
* Generates product rankings
* Generates seller rankings
* Creates data visualizations

## Project Structure

```text
sales-data-analysis/
│
├── data/
│   └── sales.xlsx
├── output/
│   └── sellers_rank.png
├── sales_analysis.py
├── requirements.txt
├── README.md
└── .gitignore
```

## Metrics Generated

* Total revenue
* Total products sold
* Average revenue
* Highest sale
* Product sales ranking
* Seller revenue ranking

## Visualization

The project generates a bar chart showing seller performance based on total revenue.
